Guide · AI i studiet

Byg din egen studiehub

Sæt Claude og GitHub op, lav dit eget studiemateriale, og hold dig inden for VIA's regler og ophavsretten. Ti korte trin.

    Trin 1

    Hvad du bygger

    En mappe på din computer, hvor Claude hjælper dig med at lave quizzer, formeloverblik og forklaringer til dine fag. Det færdige materiale kan du lægge på en gratis hjemmeside via GitHub.

    Det skal du bruge

    • 1–2 timer første gang
    • En computer (Windows eller Mac)
    • En gratis GitHub-konto
    • Et betalt Claude-abonnement til Claude Code (Pro eller højere)

    Det får du

    • En AI, der kender dine fag og dine regler
    • Faste opskrifter ("skills") til quiz og overblik
    • Din egen hjemmeside med dit materiale

    Tre begreber

    • Claude Code: Claude, der arbejder direkte i dine filer og mapper, i stedet for i et chatvindue.
    • Git og GitHub: Git gemmer versioner af dine filer. GitHub gemmer dem online og kan vise dem som hjemmeside (GitHub Pages).
    • Skill: En opskrift i en tekstfil, som fortæller Claude, hvordan en bestemt opgave skal løses hver gang.
    Ingen kode nødvendigDu skriver på dansk, hvad du vil have. Claude skriver koden, og du tjekker resultatet.
    Trin 2 · 2 minutter

    Må jeg det?

    Inden du går i gang: otte situationer. Gæt, og se forklaringen.

    Reglerne kan variere fra prøve til prøveReglerne for AI står i studieordningen og eksamensbeskrivelsen for den enkelte prøve. Læs dem, før du bruger AI til noget, der skal afleveres. I tvivl: spørg din underviser.
    Trin 3

    Opret konti

    GitHub

    1. Opret en konto på github.com/signup.
    2. Ansøg om GitHub Student Developer Pack med din studiemail. Det giver dig gratis GitHub Pro, mens du studerer.

    Claude

    1. Opret en konto på claude.ai.
    2. Claude Code kræver et betalt abonnement (Pro eller højere). Gratisversionen kan bruges til almindelig chat.
    3. Gå til indstillingerne under Privatliv, og beslut, om dine samtaler må bruges til at forbedre modellen. Slå det fra, hvis du er i tvivl.
    Tjek, hvad VIA tilbyderUndersøg, om VIA stiller et AI-værktøj til rådighed med dit VIA-login. Løsninger, som skolen har en aftale om, beskytter ofte dine data bedre.
    Alt, Claude læser, sendes til behandlingNår Claude læser en fil, sendes indholdet til Anthropics servere. Læg derfor kun materiale i din studiemappe, som du har ret til at bruge med AI. Mere om det i trin 5.
    Trin 4

    Installér værktøjerne

    Tre programmer. Vælg dit styresystem øverst på siden.

    1 · VS Code

    Gratis editor, hvor du ser dine filer og taler med Claude. Hent den på code.visualstudio.com.

    2 · Git

    Hent installeren på git-scm.com, eller kør dette i PowerShell:

    winget install --id Git.Git -e

    Åbn Terminal, og kør:

    xcode-select --install

    3 · Claude Code

    Nemmest: Åbn VS Code → Udvidelser (Ctrl+Shift+XCmd+Shift+X) → søg efter Claude Code fra Anthropic → Installér. Åbn Claude-panelet, og log ind med din Claude-konto.

    Eller i terminalen:

    PowerShell
    irm https://claude.ai/install.ps1 | iex
    Terminal
    curl -fsSL https://claude.ai/install.sh | bash

    Tjek, at det virker

    git --version
claude --version

    Begge skal svare med et versionsnummer. Gør de ikke det, så luk terminalen, åbn den igen, og prøv en gang til.

    Trin 5

    Lav din studiemappe

    Strukturen er det vigtigste. Den holder det private adskilt fra det, du deler.

    Studie/
├── CLAUDE.md          ← Claudes husregler (trin 6)
├── .gitignore         ← det, der ALDRIG må på GitHub
├── kilder/            ← PRIVAT: dine egne noter og opgaver
│   └── MEM1/
├── fag/               ← dit eget materiale, som må deles
│   └── MEM1/
└── .claude/
    └── skills/        ← dine faste opskrifter (trin 8)

    Opret mapperne i PowerShell (fra fx Dokumenter):

    mkdir Studie\kilder, Studie\fag, Studie\.claude\skills

    Opret mapperne i Terminal:

    mkdir -p Studie/{kilder,fag,.claude/skills}

    Åbn mappen i VS Code: File → Open Folder → Studie.

    Opret .gitignore

    Lav en fil med navnet .gitignore i Studie-mappen. Den sørger for, at dine private kilder aldrig bliver lagt på GitHub:

    .gitignore
    # Private kilder kommer aldrig på GitHub
kilder/

# PDF'er fra andre holdes ude (fjern linjen, hvis du selv laver PDF'er)
*.pdf

# Hemmeligheder
.env

    Hvad må ligge i kilder/?

    Godt at bruge

    • Dine egne noter fra timerne
    • Dine egne opgaveløsninger
    • Kursusplaner og eksamensspørgsmål, du har fået udleveret
    • Åbne kilder (fx frie lærebøger og standarder med åben licens)

    Kun med tilladelse

    • Lærebøger og kapitler som PDF
    • Kompendier, du har fået via VIA (Copydan-kopier)
    • Underviserens slides: spørg underviseren først
    • Alt med persondata om andre
    Trin 6

    Skriv dine husregler

    CLAUDE.md er en tekstfil, som Claude læser hver gang. Her fortæller du, hvem du er, hvordan du lærer bedst, og hvilke regler der gælder.

    Lav filen i roden af Studie-mappen, og tilpas teksten i [klammer]:

    CLAUDE.md
    # Mit studie
Jeg læser [uddannelse] på VIA, [semester]. Fag: [fag 1], [fag 2], [fag 3].

## Sådan hjælper du mig
- Svar på dansk. Forklar, som om jeg ikke har læst kapitlet endnu.
- Forklar trin for trin, og stil mig et kontrolspørgsmål bagefter.
- Når jeg beder dig tjekke en opgave: giv et hint først, ikke hele løsningen.
- Skriv formler med forklaring af alle symboler og enheder.
- Sig tydeligt, når du er usikker. Henvis til kapitel og side, så jeg kan tjekke.

## Regler
- Alt i fag/ skal være mine egne formuleringer.
  Kopiér aldrig tekst eller figurer fra bøger eller slides.
- Mappen kilder/ er privat og må aldrig udgives.
- Ingen persondata om andre (navne, karakterer, CPR) i filer.
- Skriv aldrig tekst til eksamensafleveringer for mig.
    Den bliver bedre over tidHver gang Claude gør noget, du ikke kan lide, så tilføj en linje i CLAUDE.md. Eller bed Claude om at gøre det: "Tilføj til CLAUDE.md, at du altid skal bruge SI-enheder."
    Trin 7

    Din første samtale

    Åbn Claude-panelet i VS Code, og prøv en af disse. Ret navne på fag og filer til dine egne.

    Gode og dårlige vaner

    Træningsmakker

    • "Forklar det, og stil mig spørgsmål"
    • "Find fejlen, men giv kun et hint"
    • "Lav en quiz ud fra mine noter"
    • "Hvor i bogen kan jeg læse mere?"

    Ghostwriter

    • "Skriv indledningen til vores rapport"
    • "Her er hele bogen, lav mine noter"
    • "Løs opgaven, så jeg kan aflevere den"
    • Stole blindt på tallene
    AI kan tage fejlOgså i regnestykker, der ser overbevisende ud. Regn altid efter mod bogen, facit eller en håndberegning, før du stoler på et resultat.
    Trin 8

    Lav din første skill

    Når du har bedt om det samme tre gange, så gør det til en skill. Så får du samme kvalitet hver gang med én kommando.

    Lav mappen .claude/skills/quiz/ og filen SKILL.md i den:

    .claude/skills/quiz/SKILL.md
    ---
name: quiz
description: Lav en quiz med 10 spørgsmål til et kapitel ud fra mine noter.
  Brug når jeg skriver /quiz eller beder om en quiz.
---

# Quiz-opskrift
1. Læs mine noter om emnet i kilder/<fag>/.
2. Lav 10 multiple choice-spørgsmål: 4 lette, 4 mellem, 2 svære.
3. Forkerte svar skal være troværdige og omtrent lige så lange som det rigtige.
4. Bland svarenes rækkefølge, hver gang siden åbnes.
5. Vis kort forklaringen efter hvert svar.
6. Gem quizzen som én HTML-fil i fag/<fag>/.
7. Vis mig spørgsmålene, så jeg kan rette dem, før du er færdig.

    Brug den sådan i Claude-panelet:

    /quiz MEM1 kapitel 2

    Idéer til flere skills

    • /overblik: et formeloverblik pr. kapitel med symboler, enheder og sidehenvisninger
    • /flashcards: vendekort med formlens navn på forsiden og formlen på bagsiden
    • /forklar: et begreb forklaret i tre niveauer, fra hverdagssprog til eksamensniveau
    Trin 9

    Læg det på GitHub

    Så har du en sikkerhedskopi, og du kan dele dit materiale som hjemmeside.

    1 · Lav et repository

    Gå til github.com/new, kald det studie, vælg Private, og klik Create repository.

    2 · Upload mappen

    Nemmest: Bed Claude om det: "Læg Studie-mappen op i mit GitHub-repo studie. Tjek først, at intet fra kilder/ kommer med." Claude kører kommandoerne og forklarer dem.

    Eller selv, i terminalen inde i Studie-mappen (skift BRUGERNAVN ud):

    git init
git add .
git status
git commit -m "Første version"
git branch -M main
git remote add origin https://github.com/BRUGERNAVN/studie.git
git push -u origin main
    Kig på git status, før du committerListen viser, hvad der bliver uploadet. Står der noget fra kilder/ eller en PDF fra en bog, så stop og ret .gitignore.

    3 · Gør det til en hjemmeside (valgfrit)

    1. I dit repo: Settings → Pages.
    2. Under Source: vælg Deploy from a branch, derefter main og / (root), og klik Save.
    3. Efter et minut ligger siden på BRUGERNAVN.github.io/studie.
    Hjemmesiden er offentligSelvom dit repo er privat, kan alle på internettet se siden. GitHub Pages fra et privat repo kræver GitHub Pro, som du får med Student Pack. Læg kun dit eget materiale derop.
    Trin 10

    Tjeklisten før du deler

    Gå listen igennem, hver gang du lægger noget nyt op.

    Klar til at deleDel linket med dit hold, og lav videre med én skill ad gangen.

    Kilder og videre læsning

    • Tekst & Node (Copydan): Alt om kopiaftalen. Standardaftalen dækker ikke prompts til AI-værktøjer, og det er ikke tilladt at uploade tekster til AI-tjenester uden deres særskilte AI-aftale. Kopier må ikke deles på åbne hjemmesider.
    • VIA: retningslinjer for brug af generativ AI ved eksamener (fx Socialrådgiveruddannelsen, opdateret 25.09.2025): AI må ikke være medforfatter og må ikke angives som kilde. De gældende regler for din prøve står i studieordningen og eksamensbeskrivelsen.
    • Anthropic: dokumentation for Claude Code.
    • GitHub: dokumentation for GitHub Pages.

    Guiden er ikke juridisk rådgivning. Er du i tvivl om ophavsret, så spørg VIA's bibliotek eller din underviser.
